    Card box

    Put a card in the rig. Drag the yellow box so it lines up with the outer edge of the whole card, and drag its corner to resize. You only do this once for your rig.

    After a test read, a green box shows where it found the name and a cyan box the number.

    Settings

    Both come from your Apps Script web app. See the README setup steps.

    Advanced (leave these alone unless something is off)

    Matching: when to log without asking

    How close the read must be to a card name. Wrong cards logged → raise. Picker pops up for clear reads → lower.

    How far the best guess must beat the second best. Similar names mixed up → raise.

    Card detection: when a card gets read

    How long a card must sit still. Read while sliding → raise. Cranking feels slow → lower.

    Meter says "moving" with no new card (shaky rig) → raise. New cards missed → lower.

    Card never gets read (flicker) → raise. Reads happen mid-motion → lower.

    Sync

    Sends to the sheet once this many are waiting. It also sends every minute.
